# 🌤️ Weather App

A simple and elegant Weather App that allows users to get real-time weather information of any city using the **OpenWeatherMap API**.  
This project is built using **HTML**, **CSS**, and **JavaScript**, with modern practices like **async/await**, **error handling**, and **dynamic DOM updates**.

---

## 🔮 Features

- 🌍 Get weather details of any city worldwide
- 📦 Uses OpenWeatherMap API for real-time data
- 🌡️ Shows temperature and weather description
- ⚠️ Displays error message for invalid cities
- 🧠 Async/Await + Error Handling in JavaScript
- 🧹 Clean UI with hidden/show sections

---

## 🖥️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- OpenWeatherMap API  

---

## 🔑 API Key

This app uses a free **API key from OpenWeatherMap**.
